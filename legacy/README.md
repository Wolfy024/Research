# Archived experiments

This directory preserves the repository's original watermarking and encryption
prototypes for historical reference. They are not part of the installable
SpectralMark package, CI, or published results.

Known limitations include hard-coded local paths, incomplete model definitions,
standalone GAN code that is not wired into training, reconstruction
autoencoders without watermark payloads, and undocumented metrics. Do not use
these files as the implementation behind the root README.
